1. PROJECT CONTEXT
What this is: A web app used by a college exam cell to generate
academic question papers. Professors upload question banks
or raw notes/syllabus; the system tags questions with Bloom's
Taxonomy Level (BTL) and Course Outcome (CO); an algorithm
assembles a balanced paper matching mark distribution and
academic rigor rules; the paper is rendered into a college's
exact official template; the final PDF is cryptographically signed,
watermarked, and access-controlled before release.
Long-term goal (architect for this now, do not build billing for
it): After successful use at our own college, this will be sold as
a paid multi-tenant SaaS product to other colleges. Build with
multi-tenancy from the start — retrofitting tenant isolation later
is far more dangerous for a security-sensitive product than
building it in now.
Existing stack (confirm against actual repo, do not assume
unchanged):

Framer Motion, axios, html2pdf.js, recharts
Backend: Node.js + Express, JWT in HttpOnly cookies,
EmailJS for OTP, bcrypt
Database: Firebase Firestore via firebase-admin
AI: Google Gemini API ( @google/genai )
